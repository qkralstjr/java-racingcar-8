# java-racingcar-precourse

## 기능 구현 목록

### 입력
- [x] 자동차 입력받기
- [x] 자동차 이름 5자 이하 검증
- [x] 자동차 이름 공백 검증
- [x] 시도할 횟수 입력받기
- [x] 시도 횟수 양수 검증

### 자동차 도메인
- [x] 자동차 생성
- [x] 자동차 전진 여부 판단 (0~9 랜덤값, 4 이상일 때 전진)
- [x] 자동차 현재 위치 반환
- [x] 자동차 이름 반환

### 게임 진행
- [x] 사용자 입력 횟수만큼 게임 라운드 진행
- [x] 각 라운드마다 모든 자동차 전진 판단 및 위치 업데이트
- [x] 각 라운드 결과 출력

### 우승자 판단
- [x] 모든 자동차 중 최대 위치값 계산
- [x] 최대 위치값과 동일한 위치인 자동차들 찾기 (복수 우승 가능)
- [x] 우승자 목록을 쉼표로 구분하여 출력

### 출력
- [x] 각 라운드별 실행 결과 출력 (자동차 이름 : 전진거리)
- [x] 최종 우승자 출력

## 예외 처리
- [x] 자동차 이름이 5자를 초과할 경우 
- [x] 자동차 이름이 비어있을 경우 
- [x] 시도 횟수가 숫자가 아닐 경우
- [x] 시도 횟수가 0 이하일 경우
